# Revcode 0.1.2

Source: f7ff734ba9de533481587b6e288e5833042ed0bc

Revcode binaries: unsigned.

## Changes since 0.1.1

- Add persistent conversation threads with separate agent context and run history, automatic titles and date grouping, archive/unarchive, and independent selection in multiple browser tabs. Switching threads preserves unsent text, image attachments, and drawing scenes while the page stays open. Existing history appears in a legacy thread.
- Add Excalidraw drawings and image annotations. Upload, paste, or drop supported images; annotate them with shapes, arrows, text, and freehand strokes. Adjust reference-image opacity, reopen drawings, and capture the active Revit view. Editor assets and fonts are bundled locally.
- Fix Capture active view incorrectly rejecting the active model when Revit returns different managed wrappers for the same document. The capture guard now uses document equality while retaining the active-view check.
- Reduce the release payload by removing dependency source maps/type declarations and non-Windows-x64 ZeroMQ binaries. Packaging validates the staged host and production dependencies before sealing the artifact.
- Make Windows build/install launcher tests tolerate slow PowerShell startup and include subprocess errors, signals, and output in failure diagnostics.

## Install or upgrade after publication

Close Revit before activation, then run:

```powershell
pnpm add -g @aectooling/revcode@0.1.2
revcode install
revcode doctor
```

The explicit install command also handles blocked lifecycle scripts or pending registration. Existing settings and history are preserved. Installing a new npm version does not update already-running Revit processes.

## Compatibility and limitations

- Windows x64. Node.js 22.19 or newer is required for package management and CLI bootstrap; the application uses bundled Node and self-contained native helpers.
- Packaged targets: Revit 2025 build 25.4.41.14 or newer on .NET 8; Revit 2026 build 26.5.0.55 or newer on .NET 10; Revit 2027 build 27.0.10.13 or newer on .NET 10. Installation checks the packaged year, build range, and runtime. Revit 2025 on .NET 10 is not included.
- Binaries are unsigned and may trigger Revit's standard add-in prompt.
- Only one thread can run at a time. History survives host restarts within the same Revit instance; separate Revit instances have independent histories. Unsent drafts and drawing scenes are lost on page reload.
- Sending images requires an image-capable model. Native captures and desktop screenshots sent to a model go to the selected provider. Desktop automation remains experimental.
- C# executes with full trust inside Revit. Use disposable models for testing; an uncertain native operation requires inspection before further execution.

- The capture-fix PR passed full CI before merge. The final release build passed typechecking, 137 source tests, native tests, .NET 8/10 transport checks, and 16 deployment tests.
- All 137 staged-payload tests passed for the final build; all three Revit add-ins were built with locked dependencies.
- The first candidate passed all four npm/pnpm tarball installation modes and a local upgrade from 0.1.1 with doctor reporting no problems.
- Live Revit 2026.5 testing passed queries, compiler diagnostics, committed edits, and rollback checks. It exposed the active-view capture comparison bug; the corrected generated capture code then exported the view successfully in Revit.
- The final rebuilt candidate has not repeated the local upgrade or full live UI smoke test; further live testing was skipped at the maintainer's request. Revit 2025 and 2027 were built but not live-tested for this release. No real-provider conversation was sent.
