# Revcode 0.1.1

Version 0.1.1 prepares the first scoped npm release as `@aectooling/revcode` and fixes release packaging and publication. The CLI command remains `revcode`.

## Changes since 0.1.0

- Move the npm package from `revcode` to `@aectooling/revcode`, with updated installation and removal instructions. The existing `v0.1.0` tag and draft artifacts are preserved as the abandoned unscoped candidate.
- Fix isolated tarball tests to select the configured pnpm version through Corepack and approve local tarball lifecycle scripts using pnpm's source identity. Package lookup now supports the scoped name.
- Fix GitHub draft-release lookup during publication by resolving the release ID before checking its notes and assets.
- Remove the mandatory `acceptance.json` file from the release workflow and uploaded assets. Manual live-test notes are optional; automated tests, source verification, signing-policy checks, and artifact-integrity checks remain required.

## Install after npm publication

Close Revit before activation, then run:

```powershell
pnpm add -g @aectooling/revcode@0.1.1
revcode install
revcode doctor
```

The explicit `revcode install` command also handles blocked package-manager lifecycle scripts or pending registration. Settings and history are preserved by removal; use `revcode uninstall` before removing the global package.

## Compatibility and known limitations

- Windows x64; Node.js 22.19 or newer is required for installation and CLI management. The application uses bundled Node and self-contained helpers.
- Configured Revit targets: 2025 on .NET 8, 2026.5+ on .NET 10 (build 26.5.0.55 or newer), and 2027 on .NET 10. Installation checks the exact build and runtime against the packaged metadata. Revit 2025 on .NET 10 remains deferred.
- Revcode binaries are configured as unsigned for this release and may trigger Revit's standard add-in prompt.
- Revcode remains an early, full-trust prototype. C# runs inside Revit; test with a disposable project. Desktop automation is experimental, and live validation across all supported Revit targets remains a separate manual check.

See the [deployment guide](../DEPLOYMENT.md) for compatibility details, rollback, removal, and the artifact publication workflow.
